---
name: 'Mermaid architecture diagrams'
description: 'Use to create or update Mermaid diagrams for system context, sequence and cross-application data movement.'
applyTo: '**/*.mmd'
---
- Use simple readable Mermaid syntax and short labels; avoid unsupported styling.
- Distinguish confirmed components/flows from proposed/unknown relationships.
- Indicate trust/security zones and ownership only where grounded.
- If changing an existing diagram, preserve documented semantics and list changes for review.
