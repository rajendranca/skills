# Procedure
Trace producers, consumers, formats, schemas, sequencing, replay, idempotency, throughput, auth, error handling, reconciliation, monitoring and support model. Highlight failure modes and migration coexistence. Recommend validation experiments and decisions.

# Evidence discipline
Use workspace documents as primary evidence; distinguish facts and assumptions, and cite file names and relevant headings. Never assume a code repo is available.
