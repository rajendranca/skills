---
name: architecture-decision-record
description: Use when choosing between competing engineering technologies or formalizing an architecture decision.
---
# Procedure
Create ADR with title, status, date, context, decision drivers, options and tradeoffs, recommendation, consequences, evidence, open questions and review triggers. Never invent costs or benchmarks.

# Evidence discipline
Use workspace documents as primary evidence; distinguish facts and assumptions, and cite file names and relevant headings. Never assume a code repo is available.
