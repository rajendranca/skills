# Meeting notes to actionable decisions
Classify meeting content as: confirmed decisions, options considered, action items, risks/issues, dependencies, open questions, proposed follow-ups. Quote only from actual notes; avoid inventing attendee assent. Each action: provisional owner/role, expected output, time only if stated, status unknown until confirmed.
Flag decisions without approver, actions without owner, dependency without provider, and hidden assumptions. Provide concise email/Teams-style follow-up text as a draft, never send automatically.
