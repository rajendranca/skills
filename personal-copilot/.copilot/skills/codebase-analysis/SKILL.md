# Codebase Analysis
Inventory solution/build files and top-level modules; find entrypoints, configuration, external connections and persistence. Trace one representative request or data flow with path references. List missing evidence and produce a component inventory, dependency map in Mermaid, risks and questions. Never claim full coverage from a partial scan.

## Output
State observations, evidence, assumptions, prioritized actions, validation and human approval points. Do not claim actions or tests were completed unless tools actually ran.
