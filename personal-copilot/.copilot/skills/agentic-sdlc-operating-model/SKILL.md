# Agentic SDLC operating model
Map agent-assisted steps: intake, spec, architecture challenge, implementation planning, coding, test generation, independent verification, documentation, human PR approval, CI gates, controlled deployment. For each: human accountable role, permitted autonomy, required evidence, data boundary and rollback/escalation path.
Use **tiered autonomy**: A0 advisory/no writes; A1 drafting in local workspace with review; A2 supervised PR changes in scoped branches; A3 policy-constrained automation, only after proven guardrails. Never presume A3 is approved.
Pilot one low-risk pod and one repetitive activity. Define representative evaluation cases (baseline current workflow vs agentic), correctness, review effort, cycle time, escaped defects, auditability, cost, tool permissions and adoption. Scale only after security, QA, delivery and architecture stakeholders approve.
Separate developer acceleration from portfolio-level productivity and do not inflate benefits with anecdotal speed claims.
