# Azure Architecture
Map subscriptions, network boundaries, identity/RBAC, data paths, HA/DR, private endpoints, logging, cost drivers and infrastructure lifecycle. Evaluate Azure versus existing on-prem alternatives. Require current vendor documentation for exact service limits/prices and note unverified details.

## Output
State observations, evidence, assumptions, prioritized actions, validation and human approval points. Do not claim actions or tests were completed unless tools actually ran.
