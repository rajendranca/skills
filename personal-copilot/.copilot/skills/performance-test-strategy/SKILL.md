# Performance Test Strategy
Identify SLIs/SLOs and representative workload mixes. Separate baseline, peak, stress and soak. Specify instrumentation, bottleneck hypotheses, data volume, resource saturation, success criteria and before/after comparisons; never manufacture results.

## Output
State observations, evidence, assumptions, prioritized actions, validation and human approval points. Do not claim actions or tests were completed unless tools actually ran.
