# Procedure
Define scope and exclusions, agent chain, exact human gates, approved tools, read/write scopes, audit logging and measurable baselines. Measure cycle time, accepted PRs, correctness, defects, rework, engineer time, spend and adoption. Include stop criteria.

# Evidence discipline
Use workspace documents as primary evidence; distinguish facts and assumptions, and cite file names and relevant headings. Never assume a code repo is available.
