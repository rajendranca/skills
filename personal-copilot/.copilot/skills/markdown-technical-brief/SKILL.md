# Procedure
Start with intended audience and decision. Put short executive summary first; follow with context, analysis, options, risks, owners and next steps. Use clear headings, tables only when helpful, and links to source Markdown files. Label unknowns and avoid invented citations.

# Evidence discipline
Use workspace documents as primary evidence; distinguish facts and assumptions, and cite file names and relevant headings. Never assume a code repo is available.
