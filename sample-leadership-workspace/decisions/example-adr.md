# ADR-001: File ingestion architecture (example)

Status: Proposed

## Context
An existing workflow processes inbound files from on-prem systems. The organization is considering an Azure-managed ingestion design.

## Options
1. Retain current scheduled ingestion.
2. Move orchestration to Azure Data Factory with approved network connectivity.
3. Implement a custom managed service.

## Decision
Not yet made. Assess security, support model, recoverability, cost and delivery effort.
