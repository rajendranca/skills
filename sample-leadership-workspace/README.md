# Engineering leadership workspace (non-repository)
This folder is for approved Markdown notes, architecture diagram sources, triage artifacts, ADRs, QA oversight and pod portfolio pulse reports. **Git is optional.** Everything with `.template.md` is intentionally blank: copy and fill using approved corporate data. Do not mistake templates for factual application documentation.

Suggested flow: incoming note → `01-intake` → `02-architecture` (if needed) → `03-delivery` → `04-quality` → `05-leadership` decision brief. `06-agentic-sdlc` holds pilot methods and measurements.

Personal agents are installed at `~/.copilot/agents/`; personal skills at `~/.copilot/skills/`. The workspace contains no connection credentials or integrations by default.
